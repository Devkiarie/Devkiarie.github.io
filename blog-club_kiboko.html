Building Club Kiboko – A 2-Player Canvas Game

HTML Canvas JavaScript Game Dev Multiplayer

Project Overview

Club Kiboko is a lightweight, browser-based 2-player fighting game built entirely using the HTML5 canvas API, custom JavaScript logic, and creative CSS animations. The game pits two animal-inspired warriors in a duel, and is designed for keyboard combat with real-time animations, hit detection, and a health system.

Designed as a passion project (and a break from saving Gotham), the aim was to build a fun, responsive, and retro-style game that works across devices without any frameworks. Here's how it came together:

Key Features Implemented:

Canvas-Based Rendering
The game world is rendered entirely within an HTML canvas element using 2D drawing APIs. From sprite animations to health bars and stage design, everything is drawn and animated frame-by-frame.

2-Player Keyboard Controls
Both players use the keyboard (WASD vs Arrow keys) to control movement, jumps, and attacks. Real-time key listeners handle simultaneous inputs.

Collision Detection System
A custom logic checks for overlapping bounding boxes to detect hits between characters and apply damage, trigger knockbacks, or block moves.

Dynamic Health Bars
Each player has a health bar that updates live as damage is taken. When one player’s HP hits zero, the game declares a winner and offers a restart.

Pixel Art Characters
Sprites were created using Piskel, an open-source sprite editor, then animated manually through sprite sheets and canvas `drawImage()` operations.

Technical Stack

  • Frontend: HTML5, CSS3, JavaScript (vanilla)
  • Game Engine: Custom (no frameworks)
  • Graphics: Canvas API, Piskel sprites
  • Hosting: GitHub Pages / Vercel

Key Challenges

One of the main challenges was building a responsive and reliable collision system without using external physics libraries.


// Simple collision check
function isColliding(rect1, rect2) {
    return (
        rect1.x < rect2.x + rect2.width &&
        rect1.x + rect1.width > rect2.x &&
        rect1.y < rect2.y + rect2.height &&
        rect1.y + rect1.height > rect2.y
    );
}

Lessons Learned

Developing Club Kiboko taught me a lot about game loops, frame optimization, handling simultaneous key presses, and keeping state organized. Most importantly, I learned to prioritize simplicity and performance in browser-based games.

The final version of the game offers a nostalgic, arcade-style battle experience playable directly in the browser—no installs, no lag, just action.
