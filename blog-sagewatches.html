WatchShop: Mastering Dark Mode

CSS Variables LocalStorage UI Themes

The Theme System Challenge

WatchShop was a luxury timepiece e-commerce site that demanded premium aesthetics. The client wanted:

- Seamless light/dark mode switching
- Theme persistence across sessions
- Custom accent colors for different product lines
- Smooth transitions between themes

This became my deepest dive into CSS variables and browser storage APIs.

Implementing the Theme Engine

The solution involved multiple interconnected systems:

1. CSS Variable Architecture:
Created a comprehensive set of design tokens:

:root {
    --primary: #0066cc;
    --text: #333333;
    --background: #ffffff;
    /* etc. */
}

[data-theme="dark"] {
    --primary: #3399ff;
    --text: #f0f0f0;
    --background: #121212;
}

2. JavaScript Theme Manager:
Built a class to handle:
- System preference detection (prefers-color-scheme)
- User preference storage (localStorage)
- Theme switching without flashes

3. UI Controls:
Designed an elegant theme switcher component that reflected the current state.

Technical Stack

  • Core: React with TypeScript
  • Styling: CSS Modules with variables
  • State Management: Context API for theme
  • Persistence: localStorage API

Lessons That Transformed My Approach

This project taught me invaluable lessons about design systems:

- Design Tokens: Learned to abstract colors, spacing, etc. into variables
- Performance: Discovered how to prevent layout thrashing during theme changes
- User Preference: Implemented system-level preference detection
- Accessibility: Ensured proper contrast ratios in both themes

The WatchShop theme system became a foundational pattern I've reused in every project since.
