Task Manager CLI: Python Priority Queues

Python CLI Data Structures

Efficient Task Prioritization

This command-line application helps users manage tasks with three priority levels, featuring:

Priority Queues

Tasks are automatically sorted into high, medium, and low priority queues

Persistent Storage

All tasks are saved to JSON file between sessions

Completion Tracking

Timestamps track when tasks are created and completed

Technical Implementation

Priority Queue System

                            
                                def complete_task(self):
    # Get next task based on priority
    if self.high_priority:
        task_id = self.high_priority.popleft()
    elif self.medium_priority:
        task_id = self.medium_priority.popleft()
    elif self.low_priority:
        task_id = self.low_priority.popleft()
    else:
        print("No tasks available!")
        return
        
    task = next((t for t in self.tasks if t['id'] == task_id), None)
    if task:
        task['completed'] = True
        task['completed_at'] = datetime.now().strftime('%Y-%m-%d %H:%M:%S')
        self.save_tasks()

JSON Data Persistence

                            
                                def save_tasks(self):
    data = {
        'tasks': self.tasks,
        'high_priority': list(self.high_priority),
        'medium_priority': list(self.medium_priority),
        'low_priority': list(self.low_priority)
    }
    with open('tasks.json', 'w') as f:
        json.dump(data, f, indent=2)
