Wilsmar: Conquering the MERN Stack

MongoDB Express React Node.js

The Fullstack Challenge

Wilsmar Wines & Spirits was my first complete MERN stack application, featuring:

- Custom backend API with Express
- MongoDB database with complex product relationships
- React frontend with admin dashboard
- User authentication with JWT

This project marked my transition from frontend to fullstack development.

Building the Backend Architecture

The backend development was particularly educational:

1. API Design: Created RESTful endpoints for all operations
2. Database Modeling: Designed schemas for products, users, orders
3. Authentication: Implemented JWT with proper security
4. Error Handling: Built comprehensive error middleware

The process of connecting frontend to backend taught me the importance of clear API documentation.

Frontend-Backend Integration

Key integration challenges included:

- Managing authentication state across the app
- Handling loading and error states for API calls
- Implementing optimistic UI updates
- Securing admin routes

This experience fundamentally improved my understanding of client-server communication.

Technical Stack

  • Frontend: React with Vite
  • Backend: Node.js with Express
  • Database: MongoDB with Mongoose
  • Authentication: JWT with HTTP-only cookies
  • Deployment: Render for backend, Vercel for frontend

Lessons in Fullstack Development

Wilsmar taught me:

- API Design: How to structure endpoints logically
- Database Relations: Modeling complex product relationships
- Security: Proper authentication implementation
- DevOps: Managing separate frontend/backend deployments

This project remains my most comprehensive fullstack implementation to date.
