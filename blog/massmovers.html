Building a Fullstack Logistics Platform

Vite Node.js Firebase Paystack

Project Overview

Mass Movers Limited required a comprehensive logistics management platform to support their rapidly expanding operations. The primary goal was to build a responsive and intuitive web application that would allow seamless interaction between the company’s administrators and its users, while offering a range of tools to optimize order handling and customer engagement.

To meet these needs, I developed a React-based web application powered by Vite, which offers lightning-fast development and build times thanks to its native ES module support. Here's how the system was structured:

Key Features Implemented:

Order Management System
Users can easily place orders and track their current status (e.g., dispatched, released, etc.). The backend integrates with the frontend to ensure real-time updates using RESTful APIs.

Admin Dashboard
Built with modular React components, the admin interface allows:
1. Adding/removing products
2. Editing prices and inventory
3. Categorizing items dynamically
4. Viewing user subscriptions and order logs

User-Facing Interface
The UI focuses on accessibility and performance. Users can:
1. Filter available products by category, price, or availability
2. View detailed product pages
3. Subscribe to newsletters and updates

Advanced Filtering System
A custom filter logic was implemented to allow users to refine their product search dynamically using React state hooks and form inputs tied to product metadata.

Chatbot Integration
A lightweight chatbot was included using a custom-built React component. It retrieves admin-curated responses or product FAQs and guides users through common queries.

Newsletter & Email Service
The system uses a mailing service (e.g., EmailJS or a backend API with Nodemailer) to send bulk or individual emails to users subscribed via the frontend. Admins can draft and send these directly from the dashboard.

Technical Stack

  • Frontend: Vite, React,
  • Backend: Node.js, Express
  • Database: Firebase, cloudinary
  • financial: Paystack for finance management
  • Email: EmailJS
  • Deployment: vercel

    "how are you": "I'm just a bot, but I'm always ready to help!"
    };
                      
    if (predefinedResponses[lowerUserInput]) {
    return res.json({ answer: predefinedResponses[lowerUserInput] });
